# Today Card 📚

An interactive daily reading and self-care card, inspired by my SwiftUI Today Cards from the Stacked iPhone app.

## Features
- Daily reading progress and pages read
- Daily vibe and BookTok word of the day
- DO / DON'T prompts
- Tickable self-care basics
- Daily reset and completion celebrations

## How to Use
This card is hosted using GitHub Pages and can be embedded into a Notion dashboard.

## Built With
HTML, CSS and JavaScript.

Created for my November Reading Challenge.
